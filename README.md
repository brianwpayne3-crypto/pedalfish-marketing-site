# PedalFish Marketing Site

Marketing site for **PedalFish**, software for independent bicycle-service shops.

This repository is deliberately separate from the PedalFish application repository. It owns public positioning, marketing copy, sanitized product imagery, and the static website only. It must not contain PedalFish application/domain code, production data, or customer information.

## V1

V1 is a single-page static site intended for GitHub Pages. The immediate goal is for an independent shop owner or mechanic to quickly understand what PedalFish does, see truthful evidence of the real product, and have an easy path to start a conversation or become an early user.

The current product-story spine is:

**Take it in → See what's next → Do the work → Close the loop**

This is a working organizing concept, not locked final marketing copy.

## Development approach

V1 is intentionally simple: static HTML/CSS/JavaScript where needed, deployed with GitHub Pages. Brian + ChatGPT are the initial development lane; a separate coding agent is not required unless the site later develops complexity that justifies one.
